# ReBuild — AI-Powered Circular Construction Surplus Marketplace

> **“Buy only what you need. Sell what you don’t.”**

ReBuild is an AI-powered circular economy platform built for sustainability hackathons. It tackles construction and renovation waste by connecting suppliers of surplus materials (contractors, builders, remodelers) with small-batch demand (homeowners, repair workers, DIYers).

---

## 🔄 The Circular Flow
$$\text{BUILD} \longrightarrow \text{SURPLUS} \longrightarrow \text{REBUILD AI} \longrightarrow \text{NEXT USER} \longrightarrow \text{MEASURABLE IMPACT}$$

1. **Surplus Intake & AI Analysis**: Upload material specs or photos. AI determines intrinsic condition, assigns a 0–100 Circularity Score, and presents a 5-tier circular cascade.
2. **Dedicated Role Modes**:
   - 🏗️ **Contractor / Supplier Mode**: Upload surplus batches, monitor AI waste-risk alerts on stale lots, review and accept small-batch requests, and export ESG compliance reports.
   - 🛒 **Homeowner / Buyer Mode**: Natural language smart search (e.g. *“I need 12 white bathroom tiles under ₹500”*), 7-factor proximity matching, request exact small quantities, and avoid retail carton markups.
3. **Smart Matching Engine**: Analyzes material compatibility, lot size flexibility, structural condition, budget adherence, and transport distance footprints (*Local Reuse Recommended* vs *Distance Logistics Warning*).
4. **Measurable Sustainability Dashboard**: Live tracking of **material diverted from waste (kg)**, recirculated weight, and user financial savings with interactive trend analytics.

## 🚀 Quick Start Guide

### Prerequisites
- Node.js 18+ installed

### 1. Install Dependencies
```bash
npm install
```

### 2. Start Local Development Server
```bash
npm run dev
```
Open **[http://localhost:3000/](http://localhost:3000/)** in your browser.

### 3. Production Build
```bash
npm run build
```

## 🛠️ Technology Stack
- **Frontend**: React 18, TypeScript, Vite
- **Styling**: Tailwind CSS (Custom sustainability theme)
- **Icons**: Lucide React
- **Data Visualization**: Recharts
- **Celebration Effects**: Canvas Confetti
- **State & Storage**: Reactive React Context with Browser LocalStorage persistence

## 👥 User Roles & Differentiators
| Feature | 🏗️ Contractor / Supplier Mode | 🛒 Homeowner / Buyer Mode |
|---|---|---|
| **Primary Goal** | Upload & Monetize Job-site Surplus | Find & Request Small Batches |
| **Primary Action** | `+ Upload Surplus` | `🔍 Find Materials` |
| **AI Feature** | AI Material Analyzer & Waste-Risk Monitor | Natural Language Search & Match Engine |
| **Transaction Focus** | Accept Inbound Buyer Requests | Track Outbound Pickup & Mark Reused |
| **Analytics** | Job-site Inventory & Enterprise ESG | Personal Circular Badges & Savings |

## ⚖️ Quality & Environmental Disclaimer
- Condition and suitability must be verified before use. ReBuild does not certify materials for structural or safety-critical applications.
- All environmental metrics and kg diverted figures are transparent engineering estimates calculated from verified item unit weights.
